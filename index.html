01 — About

From development to quality engineering.

I’m a Junior SQA Engineer with professional experience testing web applications, especially WordPress and Elementor-based websites. My strongest work is in UI/UX validation, responsive testing, functional and regression testing, and checking implemented pages against Figma designs.

Before moving into QA, I worked as a Software Engineer Intern, where I developed a Laravel/PHP/MySQL-based dormitory management system. This development background helps me understand application workflows, implementation constraints, and the developer perspective, allowing me to collaborate effectively with development teams.

I’m currently expanding my expertise in test automation, API testing, SQL, Git/GitHub, and performance testing. I’ve built a UI automation project using WebdriverIO to automate end-to-end scenarios on the SauceDemo e-commerce application, including authentication, cart, checkout, product filtering, order completion, and test reporting.

My career goal is to transition into an Automation Test Engineer / Quality Engineer role, combining my strong manual testing foundation with automation and software engineering practices.
